# 10 · 检索策略手册

## 基本原理

- 索引:SQLite FTS5 `trigram` 分词(字符三元组),适合无空格的古汉语。
- 查询 ≥3 字:走 FTS5 短语匹配(快,毫秒级)。
- 查询 <3 字:自动回退 `LIKE` 精确子串扫描(慢一些但不漏)。
- `--like` 可强制子串匹配(用于验证 FTS 结果完整性)。

## 检索词构造

1. **从具体到宽泛**:先试最有辨识度的短语("觀其脉證,知犯何逆"),
   不中再缩短("知犯何逆"→"何逆")。
2. **方剂查询三件套**:方名(桂枝湯)→ 主治条文关键词(中風+汗出)→
   药物组合(桂枝+芍藥 各自检索取交集)。
3. **药物查询**:本草类书(本草綱目、神農本草經)用 `--book` 限定;
   注意古名/别名:甘草=國老、大黃=將軍、人參古作人蔘、茯苓古作伏苓。
4. **概念查询**:古籍不用现代术语。"高血压"检索不到,应转换为古籍语汇:
   眩暈、頭風、肝陽;"糖尿病"→消渴;"痛风"→痛痹、白虎歷節。

## 异体字与通假字速查

命中为空时,逐一尝试替换:

| 今常用 | 语料中可能写作 |
|---|---|
| 熱 | 𤍠 |
| 發 | 𤼵 |
| 陰 | 隂 |
| 咳 | 欬 |
| 痹 | 痺 |
| 臟 | 藏(五藏) |
| 智 | 知 |
| 濕 | 溼 |
| 針 | 鍼 |
| 强 | 強 |
| 煮 | 煑 |
| 微 | 㣲 |
| 症 | 證、証 |
| 拘攣 | 拘挛、拘急 |

技巧:异体字多出现在早期底本(宋本伤寒论等);若某书检索屡屡为空,
先 `get <书名> --limit 5` 看几段实际文本,了解该书用字习惯再构词。

## 结果为空的完整排查清单

1. 查询词是否含简体?(工具会在 stderr 提示)
2. 缩短到 2-4 字核心词。
3. 换异体字(上表)。
4. 换同义古语(如"腹痛"→"腹中痛"→"腹中急痛")。
5. 该书是否在库内?`list --keyword` 确认;书名是否需要 `_1` 后缀或全角括号。
6. 概念是否为现代术语?转换为古籍语汇。
7. 以上全部尝试后仍为空,才可以下"库内未检得"的结论,并列出尝试过的检索词。

## 大批量/研究型任务

- 需要穷尽某词在全库的分布时,提高 `--limit`(如 200),按书统计命中数。
- 跨书比较条文:对每本书单独 `search --book`,再逐条 `get --context 1` 取全文对齐。
- `build --jsonl` 会导出 `data/corpus.jsonl`(每段一行 JSON),
  可供你写临时脚本做词频、共现等定量分析——分析脚本写到临时目录,不要污染语料。
