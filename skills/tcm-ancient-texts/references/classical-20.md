## 一、理论基础层(战国—东汉)

### 1 《黄帝内经素问》

| 项目 | 内容 |
|---|---|
| 库内书名 | `黃帝內經素問` |
| 作者/年代 | 战国至西汉佚名，唐·王冰次注；公元前475—9年 |
| 底本 | 明嘉靖间刻本（美国国会图书馆藏） |
| 规模 | 445段，约11万字；83篇；录文品质 2%（异体字多） |
| 检索优先 | **理论·病机·五行·四时养生·阴阳·五脏** |

**内容特征**  
《素问》奠定中医基础理论体系。问答体，以黄帝问、岐伯答为主体，涵盖阴阳五行、脏腑经络、病因病机、诊法治则。代表性篇章：《上古天真论》(养生)、《阴阳应象大论》(阴阳纲领)、《五脏生成》(藏象)、《热论》(六经热病)、《痹论》(痹证)、《痿论》(痿证)、《玉机真脏论》(脏气与预后)。

**实检段落示例**
```
《黃帝內經素問》· 卷第一 / 上古天真論篇第一 · 段8
昔在黃帝，生而神靈……上古之人，其知道者，法於陰陽，和於術數，
食飲有節，起居有常，不妄作勞，故能形與神俱，而盡終其天年，度百歲乃去。
```

**检索策略**  
- 查询须用繁体：证→證、脏→臟、经→經
- 录文品质 2% 意味大量异体字，命中空时换写法：欬→咳、痺→痹、𤍠→熱
- 重要篇章直取：`get 黃帝內經素問 --section 痹論篇 --limit 5`

**必搜章节**(经子进程实际验证,`--section` 可直接匹配)  
- `上古天真論篇第一` — 全書開篇總綱，論養生天真、腎氣天癸盛衰規律，奠定中醫「治未病」與生命觀的理論起點(命中3段,如:「昔在黃帝，生而神靈，弱而能言，幼而徇齊，長而敦敏，成而登天。乃問於天師曰：余聞上古之人，」)
- `四氣調神大論篇第二` — 四時養生（春夏秋冬）與陰陽相應的綱領性條文，「春夏養陽秋冬養陰」「聖人不治已病治未病」出處(命中3段,如:「春三月，此謂發陳，天地俱生，萬物以榮，夜臥早起，廣步於庭，被髮緩形，以使志生，生而勿殺，」)
- `陰陽應象大論篇第五` — 陰陽五行學說最系統、最常被後世引用的核心理論篇，「陽化氣陰成形」「治病必求於本」等綱領性論述所在(命中3段,如:「黃帝曰：陰陽者，天地之道也，萬物之綱紀，變化之父母，生殺之本始，神明之府也，治病必求於本。」)
- `至真要大論篇第七十四` — 「病機十九條」出處，是中醫病機辨證理論中被歷代醫家引用頻率最高的條文之一(命中3段,如:「黃帝問曰：五氣交合，盈虛更作，余知之矣。六氣分治，司天地者，其至何如？岐伯再拜對曰：」)
- `靈蘭秘典論篇第八` — 以「十二官」比喻論五臟六腑功能與相互關係，臟腑理論的經典比擬篇，臨床辨臟腑常引(命中1段,如:「黃帝問曰：願聞十二臟之相使，貴賤何如？岐伯對曰：悉乎哉問也，請遂言之。心者，君主之官也，」)

### 2 《灵枢》

| 项目 | 内容 |
|---|---|
| 库内书名 | `靈樞` |
| 作者/年代 | 春秋战国佚名 |
| 底本 | 明赵府居敬堂刊本；四库全书文渊阁本 |
| 规模 | 476段，约7.9万字；81篇 |
| 检索优先 | **经络腧穴·针灸治法·经脉循行·营卫气血** |

**内容特征**  
《灵枢》即《针经》，是针灸学的奠基文献。以十二经脉、奇经八脉、五腧穴为核心。代表篇章：《九针十二原》(针刺原理)、《经脉第十》(十二经脉循行与是动所生病)、《营卫生会》(营卫气的生成与运行)、《本神》(七情与五志)、《天年》(生命节律)。

**实检段落示例**
```
《靈樞》· 經脈第十 · 段66
經脈者，所以能決死生，處百病，調虛實，不可不通。
人始生，先成精，精成而腦髓生，骨為幹，脈為營，筋為剛，肉為牆……
```

**检索策略**  
- 经穴名多异体：`俞`/`腧`/`輸`互换搜索
- 十二经脉循行在段66起约40段，可 `get 靈樞 --section 經脈第十 --limit 40`

**必搜章节**(经子进程实际验证,`--section` 可直接匹配)  
- `經脈第十` — 全書篇幅最大，詳載十二經脈循行路線及「是動則病」「所生病」證候，為經絡學說核心中的核心，臨床與理論引用頻率最高(命中3段,如:「雷公問於黃帝曰：禁脈之言，凡刺之理，經脈為始，營其所行，制其度量，內次五藏，外別六府」)
- `九鍼十二原第一` — 全書開篇總綱，論九鍼之用、虛實補瀉及十二原穴，是理解全書針灸理論體系的綱領性篇章(命中3段,如:「黃帝問於歧伯曰：余子萬民，養百姓，而收租稅。余哀其不給，而屬有疾病」)
- `本輸第二` — 系統匯編五輸穴（井滎輸經合）及六腑下合穴，是腧穴主治與針灸取穴的基礎文獻，臨床引用率極高(命中3段,如:「黃帝問於歧伯曰：凡刺之道，必通十二經絡之所終始，絡脈之所別處，五輸之所留，六府之所與」)
- `邪氣藏府病形第四` — 論邪氣中人途徑、脈色與臟腑病形之對應，是臟腑辨證與脈診理論的重要條文(命中3段,如:「黃帝問於歧伯曰：邪氣之中人也，奈何。歧伯答曰：邪氣之中人高也。黃帝曰：高下有度乎」)
- `營衛生會第十八` — 系統闡述營衛二氣生成、運行與會合機制，是營衛氣血理論的核心綱領(命中3段,如:「黃帝問於歧伯曰：人焉受氣，陰陽焉會，何氣為營，何氣為衛，營安從生，衛於焉會，老壯不同氣」)

### 3 《伤寒论（宋本）》

| 项目 | 内容 |
|---|---|
| 库内书名 | `傷寒論（宋本）` |
| 作者/年代 | 东汉·张机（张仲景）；公元200年前后 |
| 底本 | 明万历赵开美刊本（国立中央图书馆善本）；日本安政三年覆刊本 |
| 规模 | 1016段，约4.1万字；录文品质 65% |
| 检索优先 | **六经辨证·条文原文·桂枝汤·麻黄汤·经方组成** |

**内容特征**  
现存最重要的临床辨证论治专著，"方书之祖"。以六经(太阳、阳明、少阳、太阴、少阴、厥阴)分经辨证，397法、113方。条文体，每条以"太阳病……"等起首，方证对应，逻辑严谨。

**实检段落示例**
```
《傷寒論（宋本）》· 卷第二 / 辨太陽病脉證並治上第五 · 段144
太陽之為病，脉浮，頭項强痛而惡寒。
```

**检索策略**  
- 方剂名用繁体：桂枝湯、麻黃湯、承氣湯、柴胡湯
- 方证条文通常需要前后文：`get 傷寒論（宋本） --seq 156 --context 2`
- 注意书名含全角括号：必须精确使用 `傷寒論（宋本）`
- 《千金翼方》卷九收录完整《伤寒论》，可交叉比对

**必搜章节**(经子进程实际验证,`--section` 可直接匹配)  
- `辨太陽病脉證並治中第六` — 全书篇幅最大(204段)，麻黄汤、桂枝汤类加减及误治变证条文最集中，临床引用频率最高(命中3段,如:「[段216] 太陽病，項背强𠘧𠘧，無汗惡風，葛根湯主之。」)
- `辨太陽病脉證並治上第五` — 太阳病篇之首，六经辨证由此展开，桂枝汤证治与太阳病提纲首见于此(命中3段,如:「[段144] 太陽之為病，脉浮，頭項强痛而惡寒。」)
- `辨陽明病脉證並治第八` — 阳明病篇，承气汤类攻下法理论与代表条文的出处(命中3段,如:「[段548] 問曰：病有太陽陽明，有正陽陽明，有少陽陽明，何謂也？」)
- `辨少隂病脉證並治第十一` — 少阴病篇，四逆汤类回阳救逆理论所在，六经辨证寒化热化关键环节(命中3段,如:「[段687] 少隂之為病，脉㣲細，但欲寐也。」)
- `辨太陽病脉證並治下第七` — 结胸、痞证及陷胸汤、泻心汤类经方条文所在，太阳病篇重要变证部分(命中3段,如:「[段420] 問曰：病有結胷，有藏結，其狀如何？按之痛，寸脉浮，𨵿脉沈」)

### 4 《金匮要略方论》

| 项目 | 内容 |
|---|---|
| 库内书名 | `金匱要略方論` |
| 作者/年代 | 汉·张机；公元219年 |
| 底本 | 明万历赵开美刊本；四部丛刊本；四库全书本 |
| 规模 | 1320段，约3.7万字；录文品质 90% |
| 检索优先 | **杂病辨治·经方·妇科·痰饮·血痹虚劳** |

**内容特征**  
以杂病诊治为核心，25篇，涵盖内、妇、外科。每篇以脉证并治为纲，附《外台》《千金》引方。关键篇章：《痉湿暍病》《百合病》《中风历节》《血痹虚劳》《痰饮》《消渴》《妇人妊娠》《妇人产后》。

**实检段落示例**
```
《金匱要略方論》· 臟腑經絡先後病脈證第一
(实检验证录文品质优秀，方证完整)
```

**检索策略**  
- 方剂组成需看方证+煎服法：`--context 2`
- 妇科内容在最后三篇，`get 金匱要略方論 --section 婦人妊娠 --limit 10`

**必搜章节**(经子进程实际验证,`--section` 可直接匹配)  
- `臟腑經絡先後病脈證第一` — 全书总纲，提出「上工治未病」「见肝之病知肝传脾」的整体观与治未病理论，是理解全书辨治框架的理论纲领，价值最高，列为首位。(命中3段,如:「問曰：上工治未病，何也？師曰：夫治未病者，見肝之病，知肝傳脾，當先實脾」)
- `痰飲咳嗽病脈證并治第十二` — 全书篇幅最大的一篇，首创「四飲」（痰饮、悬饮、溢饮、支饮）分类，苓桂朮甘湯等系列治法皆出于此，是痰饮理论核心章节。(命中3段,如:「問曰：夫飲有四，何謂也？師曰：有痰飲，有懸飲，有溢飲，有支飲。」)
- `血痹虛勞病脈證并治第六` — 血痹虚劳病篇，黃耆桂枝五物湯、桂枝加龍骨牡蠣湯、大黃䗪虫丸等虚劳经方渊薮，为「虚劳」辨证论治的核心依据。(命中3段,如:「問曰：血痹病從何得之？師曰：夫尊榮人骨弱肌膚盛，重困疲勞汗出，臥不」)
- `水氣病脈證并治第十四` — 系统辨治风水、皮水、正水、石水、黄汗等水气病，提出腰上腰下分治大法，为水肿辨治的经典理论源头。(命中3段,如:「師曰：病有風水、有皮水、有正水、有石水、有黃汗。風水其脈自浮，外證骨節疼痛，惡風」)
- `胸痹心痛短氣病脈證治第九` — 胸痹心痛辨治总论与瓜蔞薤白白酒湯类方出处，是后世论治胸痹心痛（近似今之胸痛证候）的理论与用方源头。(命中3段,如:「師曰：夫脈當取太過不及，陽微陰弦，即胸痹而痛，所以然者，責其極虛也。」)

### 5 《神农本草经》

| 项目 | 内容 |
|---|---|
| 库内书名 | `神農本草經` |
| 作者/年代 | 秦汉佚名 |
| 底本 | 行政院中医药委员会94年文本CM096 |
| 规模 | 362段，约2.2万字 |
| 检索优先 | **药物性味·功效·上品中品下品分类** |

**内容特征**  
最早系统性本草专著，365种药物。分上品(无毒，轻身延年)、中品(有毒/无毒，补虚)、下品(多毒，攻邪)三类。每药记性味、主治、异名、产地。后世本草之祖。

**实检段落示例**
```
《神農本草經》· 卷二上藥（上品） / 三 人參 · 段4
人參 一名人銜。一名鬼蓋。味甘，微寒。無毒。
主補五臟，安精神，定魂魄，止驚悸，除邪氣，明目，開心益智。久服輕身，延年。
```

**检索策略**  
- 每药单独一段，直接按药名搜索：`search 人參 --book 神農本草經`
- 三品分类查法：`get 神農本草經 --section 上藥`/`中藥`/`下藥`

**必搜章节**(经子进程实际验证,`--section` 可直接匹配)  
- `神農本草經卷一序錄` — 全书理论纲领：三品分类、君臣佐使、七情和合、四气五味、服药法度，是全书体例与本草学理论的总纲(命中1段,如:「上藥一百二十種為君，主養命，以應天。無毒，多服、久服不傷人。欲輕身益氣，」)
- `神農本草經卷二上藥（上品） / 三 人參` — 上品补虚代表药，'补五脏、安精神、定魂魄'为历代补益方剂(四君子、独参汤)理论溯源必引条文(命中1段,如:「人參 一名人銜。一名鬼蓋。味甘，微寒。無毒。主補五臟，安精神，定魂魄，」)
- `神農本草經卷二上藥（上品） / 五 甘草` — 调和诸药之'国老'，仲景方近半数配伍甘草，考证配伍理论必查条文(命中1段,如:「甘草 一名美草。一名蜜甘。味甘，平，無毒。治五臟六腑寒熱邪氣。堅筋骨，」)
- `神農本草經卷四下藥（下品） / 二四一 附子` — 回阳救逆第一要药，'有大毒'却主治风寒痿躄拘挛，是理解本经'下品多毒治病'原则与后世四逆汤类方理论源头的核心条文(命中1段,如:「附子 一名茛。味辛，溫，有大毒。治風寒，欬逆，邪氣，溫中，金瘡，破癥堅，」)
- `神農本草經卷四下藥（下品） / 二四七 大黃` — 攻下逐瘀代表药，'荡涤肠胃、推陈致新'为承气汤类方剂理论依据，临床引用频率极高(命中1段,如:「大黃。味苦，寒，無毒。主下瘀血，血閉，寒熱，破癥瘕積聚，留飲，宿食，」)

### 6 《八十一难经》

| 项目 | 内容 |
|---|---|
| 库内书名 | `八十一難經` |
| 作者/年代 | 相传秦越人（扁鹊）所著 |

| 检索优先 | **脉诊·经络·五行生克·三焦·命门** |

**内容特征**

```

**检索策略**

**实检段落示例**

[仲景作論大法，六經各立病機一條，提揭一經綱領……]
```

**必搜章节**(经子进程实际验证,`--section` 可直接匹配)  
- `傷寒總論` — 全书理论纲领，柯琴提出'发于阳/发于阴'等辨证总法，是理解全书'六经为百病立法'方法论的总纲。经get命令验证命中3段。(命中3段,如:「[段2] 病有發熱惡寒者，發於陽也，無熱惡寒者，發於陰也。」)
- `太陽脈證` — 六经新诠体系的开篇，以'太陽之為病，脈浮頭項強痛而惡寒'提纲统摄脉证，是考察柯琴'以证名篇、不拘经文原序'编纂体例的首要入口。经get命令验证命中3段。(命中3段,如:「[段16] 太陽之為病，脈、浮、頭、項、強、痛而惡寒。」)
- `桂枝湯證上` — 桂枝汤为仲景群方之魁，柯琴于此集中阐发'方证对应'方法论，以'太陽病，頭痛發熱，汗出惡風者，桂枝湯主之'等条文逐条辨析加减变局，是该书方证学说最具代表性的示范章节。经get命令验证命中3段。(命中3段,如:「[段29] 太陽病，頭痛發熱，汗出惡風者，桂枝湯主之。」)

- `產後鬱結乳汁不通七十七` — 全书压卷篇，论肝郁致乳汁不通及通肝生乳湯治法，是后世产后缺乳从肝论治的常引依据(命中3段,如:「少壯之婦，於生產之後，或聞丈夫之嫌，或聽翁姑之誶，遂致兩乳脹滿疼痛」)

### 19 《医林改错》

| 项目 | 内容 |
|---|---|
| 库内书名 | `醫林改錯` |
| 作者/年代 | 清·王清任；公元1830年 |
| 底本 | 北京大学图书馆扫描本 |
| 规模 | 261段，约2.8万字 |
| 检索优先 | **脏腑解剖改正·活血化瘀·血府逐瘀汤·半身不遂** |

**内容特征**  
以解剖学实证精神批判古人脏腑谬误，提出"气血"新论。创立活血化瘀系列方剂——血府逐瘀汤、补阳还五汤、膈下逐瘀汤等，现代临床高频应用。

**实检段落示例**
```
《醫林改錯》· 卷上 / 醫林改錯臟腑記敘 · 段9
古人曰：既不能為良相，願為良醫……治國良相，世代皆有，著書良醫，無一全人。
其所以無全人者，因前人創著醫書，臟腑錯誤，後人遵行立論，病本先失。
```

**检索策略**  
- 方剂：`search 血府逐瘀湯 --book 醫林改錯`
- 补阳还五：`search 補陽還五湯 --book 醫林改錯`

**必搜章节**(经子进程实际验证,`--section` 可直接匹配)  
- `親見改正臟腑圖` — 王清任亲自解剖观察后绘制脏腑图及说明文字，是全书『改错』核心宗旨的理论纲领，历来是评价其解剖学贡献的必读章节(命中3段,如:「[段17] 余將親見諸臟腑顯隱之形，繪於其後，計四十二件。 [段18] 左氣門、右氣門兩管，歸中一管」)
- `血府逐瘀湯` — 全书最著名、后世临床引用率最高的方剂，主治胸中血府瘀阻诸症（头痛、胸疼等），为活血化瘀法代表方，实际命中标题为『血府逐瘀湯所治症目』及其下各症目子段(命中3段,如:「## 卷上 / 血府逐瘀湯所治症目 [段66] 血府逐瘀湯所治之病，開列於後。」)
- `補陽還五湯` — 治疗中风后半身不遂的经典名方（重用黄芪补气活血），是王清任临床贡献中流传最广、至今仍广泛应用的方剂，位于『癱痿論』篇下(命中3段,如:「## 卷下 / 癱痿論 / 補陽還五湯 [段119] 此方治半身不遂，口服歪斜，語言蹇澀，口角流涎，大便乾燥，小便頻數，」)
- `半身不遂論` — 半身不遂病机论述的纲领性条文，系统批驳历代『中风』论（风、火、气、痰诸说），奠定其『气虚血瘀』致偏瘫的独创病机观，为下卷临床理论核心(命中2段,如:「## 卷下 / 半身不遂論 [段106] 半身不遂，病本一體，諸家立論，竟不相同。始而《靈樞經》曰：虛邪偏客於身半，其入」)
- `痹症有瘀血說` — 提出痹症当从瘀血论治的创新理论，突破传统风寒湿三气致痹之说，附身痛逐瘀汤，临床与理论价值兼具(命中3段,如:「[段226] 凡肩痛、臂痛、腰疼、腿疼，或周身疼痛，總名曰痹症。明知受風寒，有溫熱發散藥不愈，明知有濕熱，用利濕降火藥無」)
