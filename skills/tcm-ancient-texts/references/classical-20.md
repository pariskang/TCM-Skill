## 一、理论基础层(战国—东汉)

### 1 《黄帝内经素问》

| 项目 | 内容 |
|---|---|
| 库内书名 | `黃帝內經素問` |
| 作者/年代 | 战国至西汉佚名，唐·王冰次注；公元前475—9年 |
| 底本 | 明嘉靖间刻本（美国国会图书馆藏） |
| 规模 | 445段，约11万字；83篇；录文品质 2%（异体字多） |
| 检索优先 | **理论·病机·五行·四时养生·阴阳·五脏** |

**内容特征**  
《素问》奠定中医基础理论体系。问答体，以黄帝问、岐伯答为主体，涵盖阴阳五行、脏腑经络、病因病机、诊法治则。代表性篇章：《上古天真论》(养生)、《阴阳应象大论》(阴阳纲领)、《五脏生成》(藏象)、《热论》(六经热病)、《痹论》(痹证)、《痿论》(痿证)、《玉机真脏论》(脏气与预后)。

**实检段落示例**
```
《黃帝內經素問》· 卷第一 / 上古天真論篇第一 · 段8
昔在黃帝，生而神靈……上古之人，其知道者，法於陰陽，和於術數，
食飲有節，起居有常，不妄作勞，故能形與神俱，而盡終其天年，度百歲乃去。
```

**检索策略**  
- 查询须用繁体：证→證、脏→臟、经→經
- 录文品质 2% 意味大量异体字，命中空时换写法：欬→咳、痺→痹、𤍠→熱
- 重要篇章直取：`get 黃帝內經素問 --section 痹論篇 --limit 5`

### 2 《灵枢》

| 项目 | 内容 |
|---|---|
| 库内书名 | `靈樞` |
| 作者/年代 | 春秋战国佚名 |
| 底本 | 明赵府居敬堂刊本；四库全书文渊阁本 |
| 规模 | 476段，约7.9万字；81篇 |
| 检索优先 | **经络腧穴·针灸治法·经脉循行·营卫气血** |

**内容特征**  
《灵枢》即《针经》，是针灸学的奠基文献。以十二经脉、奇经八脉、五腧穴为核心。代表篇章：《九针十二原》(针刺原理)、《经脉第十》(十二经脉循行与是动所生病)、《营卫生会》(营卫气的生成与运行)、《本神》(七情与五志)、《天年》(生命节律)。

**实检段落示例**
```
《靈樞》· 經脈第十 · 段66
經脈者，所以能決死生，處百病，調虛實，不可不通。
人始生，先成精，精成而腦髓生，骨為幹，脈為營，筋為剛，肉為牆……
```

**检索策略**  
- 经穴名多异体：`俞`/`腧`/`輸`互换搜索
- 十二经脉循行在段66起约40段，可 `get 靈樞 --section 經脈第十 --limit 40`

### 3 《伤寒论（宋本）》

| 项目 | 内容 |
|---|---|
| 库内书名 | `傷寒論（宋本）` |
| 作者/年代 | 东汉·张机（张仲景）；公元200年前后 |
| 底本 | 明万历赵开美刊本（国立中央图书馆善本）；日本安政三年覆刊本 |
| 规模 | 1016段，约4.1万字；录文品质 65% |
| 检索优先 | **六经辨证·条文原文·桂枝汤·麻黄汤·经方组成** |

**内容特征**  
现存最重要的临床辨证论治专著，"方书之祖"。以六经(太阳、阳明、少阳、太阴、少阴、厥阴)分经辨证，397法、113方。条文体，每条以"太阳病……"等起首，方证对应，逻辑严谨。

**实检段落示例**
```
《傷寒論（宋本）》· 卷第二 / 辨太陽病脉證並治上第五 · 段144
太陽之為病，脉浮，頭項强痛而惡寒。
```

**检索策略**  
- 方剂名用繁体：桂枝湯、麻黃湯、承氣湯、柴胡湯
- 方证条文通常需要前后文：`get 傷寒論（宋本） --seq 156 --context 2`
- 注意书名含全角括号：必须精确使用 `傷寒論（宋本）`
- 《千金翼方》卷九收录完整《伤寒论》，可交叉比对
